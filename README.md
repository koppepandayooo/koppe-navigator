# こっぺナビ

原付（50cc・125cc）向けのルート検索とナビをする、スマホ用の Web アプリ（PWA）です。原付で入れない目的地は、原付を停める場所から徒歩で案内します。
高速道路や自動車専用道路を通らないのはもちろん、**二輪の通行規制区間**や**二段階右折**まで考えてルートを出します。

**公開版: https://koppepandayooo.github.io/koppe-navigator/**

> **⚠ ベータ版（試作中）です。** 実際の道でのテスト走行はまだほとんどしていません。ルート・二段階右折・規制区間の判定や、ナビの案内が間違っていることがあります。
> 走行中にスマホを操作しないでください。**実際の標識と交通ルールを必ず優先してください。**

## 使い方

- **スマホ**: 上の URL を開いて位置情報を「許可」。ホーム画面に追加すると、アプリのように全画面で使えます
  - iPhone: Safari の共有ボタン →「ホーム画面に追加」
  - Android: Chrome のメニュー →「ホーム画面に追加」／「アプリをインストール」
- **パソコン**: ルートを調べる用（ナビは出ません）。決めたルートは「📱 スマホに送る」の QR コードでスマホに渡せます

## できること

### 原付向け
- **原付のルート**: 高速・自動車専用道路を通らない。所要時間は巡航速度（一種 30km/h、設定で変更可）で計算。候補は最大 3 本
- **二輪通行規制区間**: 日本二輪車普及安全協会の全国データ（約 480 件）を地図に表示。ルートが通るときは警告し、自動で避けて検索し直す
  - 時間帯の規制（22:00〜翌 6:00 など）は今の時刻で判定
  - 地下道・陸橋だけの規制は、ルートが横の側道を通っていれば「付近」扱い
  - 一種は「一般原付」、二種は「二輪」が対象の規制を見る
- **二段階右折**: 片側 3 車線以上の道路からの右折に「二段階」マーク。少ないルートを裏で探して、見つかれば差し替える（車線数は OpenStreetMap の情報なので目安）
- **区間ごとに原付か歩きか選べる**: 経由地・目的地の左の 🛵／🚶 で、その地点まで原付で行くか歩くかを切り替える。例: 経由地（駅など原付を停められる所）を 🛵、目的地を 🚶 にすると、経由地まで原付、そこから目的地まで歩くルートとナビになる（歩きの区間は最後にまとめる。歩いた後にまた原付に乗るルートはまだ作れない）
- **近くのバイク駐車場**: 「🅿 駐車場」で目的地から 800m 以内のバイク駐車場（バイク可の駐車場・原付可の駐輪場も）を探して地図と一覧に出す。「ここに停める」を選ぶと、原付はそこまで、そこから目的地まで歩くルートになる（OpenStreetMap に登録されているものだけ）
- **曲がる回数**: 「少なめ」「なるべく直進」を選ぶと、曲がる回数の少ないルートを優先。候補ごとに回数を表示
- **原付 → 徒歩**: 歩行者用の道や、手前が長い管理用道路・林道（山頂など）、原付で走れる道とつながっていない山道・砂利道（史跡や公園の中など）が目的地のときは、一般道の終わりで原付を停めて、そこから**歩くルート**を出す。地図に点線で表示し、時間は「原付 ○分 ＋ 徒歩 ○分」。ナビは停める場所で「ここで原付を停めて歩きます」と言って、歩きの案内に切り替わる

### 検索・地点
- 場所の検索（施設名・住所・駅）。候補に［駅］［山頂］［バス停］などの種類を表示
- **ひらがなでも検索できる**（例: 「きよみずでら」→ 清水寺）。漢字が分からない・変換できない地名に
- 住所は入力したまま残し、ピンをドラッグして細かい位置を直せる
- 地図を長押し（パソコンは右クリック）で「ここへ行く／ここから出発／経由地にする」
- **マイスポット**: 長押しで場所に名前を付けて保存すると、検索で一番上に出る
- **道路の通称**: 「○○△△線」のような都道府県道の正式名は、地図データに登録されている通称（「○○街道」など）に自動で置き換え。長押しから自分で呼び名を付けることもできる
- **ストリートビュー**: 曲がり角・二段階マーク・規制区間・長押しメニューの 📷 から、進む向きで Google マップのストリートビューを開く

### ナビ（スマホ・タブレットのみ）
- 進行方向が上になる地図、次の曲がり角と距離、日本語の音声案内
- 案内の声は **ずんだもん**（VOICEVOX）。「300メートル先、右に曲がるのだ」などの決まった案内をずんだもんの声で流し、道路名が入る案内などは端末の声で読む。設定で端末の声だけにもできる
- ルートから外れたら自動で検索し直す（走っている向きを考えて、いきなり U ターンさせない）。電波がないときは元のルートのまま案内
- 出発地を入力したときはそのルートのまま。ルートに乗るまでは「出発地点まで」と表示して待つ
- 速度表示（一種は 30km/h を超えると赤）、画面のスリープ防止

### 表示
- Google マップ風のすっきりした地図（店のアイコンや 3D の建物は出さない）
- 表示テーマ: 自動／ライト／ダーク（夜用は紺〜グレー系の配色）
- パソコンの現在地は数 km ずれることがあるので、誤差が 500m を超えるときは出発地に使わない

## 仕組み

ビルドもサーバーもない、素の HTML / CSS / JavaScript です。地図の表示は MapLibre GL（CDN から読み込み）。

| パス | 中身 |
|---|---|
| `web/index.html` | 画面の骨組み |
| `web/app.js` | アプリのロジック全部 |
| `web/style.css` | 見た目 |
| `web/sw.js` | Service Worker（オフライン時に本体を表示するため） |
| `web/data/regulations.json` | 二輪通行規制区間のデータ |
| `web/voice/phrases.json` | ずんだもんに言わせる決まり文句の一覧 |
| `web/voice/zundamon/` | ずんだもんの音声ファイル（`tools/make_voice.py` で作る） |
| `tools/scrape_jmpsa.py` | 規制区間データを協会のサイトから取得するスクリプト |
| `tools/make_voice.py` | VOICEVOX で決まり文句をずんだもんの音声ファイルにするスクリプト |
| `.github/workflows/pages.yml` | `main` に push すると `web/` を GitHub Pages に公開 |

マイスポット・履歴・設定・調べた道路の通称は、使っている端末のブラウザの中だけに保存されます（どこにも送られません）。

### ローカルで動かす

```
python -m http.server 8810 --directory web
```

http://localhost:8810 を開く。

### ずんだもんの音声を作り直す

`web/voice/phrases.json` の文を変えたら、VOICEVOX を起動した状態で実行します（文が変わったものだけ作り直します。ffmpeg があれば MP3、なければ WAV）。

```
python tools/make_voice.py
```

### 規制区間データの更新

協会のデータは毎年 6 月に更新されるので、その後に実行して `web/data/regulations.json` を上書きします。

```
python tools/scrape_jmpsa.py
```

## 使っているサービス・データ（すべて無料・API キー不要）

| 用途 | サービス |
|---|---|
| ルート検索 | [Valhalla](https://github.com/valhalla/valhalla) の公開サーバー（FOSSGIS 運営） |
| 地図 | [OpenFreeMap](https://openfreemap.org/)（© OpenStreetMap contributors） |
| 場所の検索 | [Photon](https://photon.komoot.io/)、国土地理院 住所検索、[Nominatim](https://nominatim.org/)、ひらがな→漢字は Google の変換（ひらがなだけで入力したときだけ使う） |
| 規制区間 | 一般社団法人日本二輪車普及安全協会「[二輪車通行規制区間情報](https://www.jmpsa.or.jp/society/roadinfo/)」 |
| 案内の声 | [VOICEVOX](https://voicevox.hiroshiba.jp/):ずんだもん（音声ファイルはリポジトリに入れてある） |

公開サーバーなので、個人で使う範囲にとどめています。

## 注意

- 地図データ（OpenStreetMap）の情報が実際と違うことがあります。**実際の標識と交通ルールを優先してください**
- 規制区間の位置は始点と終点だけなので、道に沿った正確な範囲ではありません
- 二段階右折は車線数からの推定です。信号のない交差点や、標識で指定された交差点は判定できません
